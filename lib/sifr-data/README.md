# بيانات متجر سِفْر

## الكتب

الملف `src/catalogue.ts` هو المصدر الوحيد لبيانات الكتب. كل سطر `book({...})` يمثل كتابًا؛ عدّل عنوانه ومؤلفه ودار نشره وتصنيفه وسعره هناك، وستظهر التغييرات في الكتالوج والفلاتر والسلة وتوصيات المساعد.

- `author` و`publisher`: قيمتان `ar` و`en`. استبدل `pending` في **سطر الكتاب المطلوب** بالقيمة المناسبة، ولا تغيّر المتغير المشترك لتعديل كتاب واحد فقط.
- `price`: سعر تجريبي بالدينار الكويتي.
- `pages: 0`: عدد الصفحات لم يُحدَّد بعد.
- `volumes: 0`: عدد المجلدات غير محدد؛ `volumeLabel` يشرح الحالة باللغتين.
- `metadataProvisional`: بيانات الطبعة لم تُؤكَّد بعد.
- `isDemo`: عنوان مؤقت قابل للاستبدال، ويظهر تنبيه بذلك للزائر.
- `category` ثم `subcategory`: رموز التصنيف المعرّفة في `src/taxonomy.ts`.
- حافظ على أرقام `id` لتجنب تغيير محتوى السلال والمفضلات المحفوظة. الرقم 11 محذوف ولا يُعاد استخدامه.

## الإعدادات

الملف `src/settings.ts` يجمع وجهات الشحن وأسعاره التجريبية، ومسارات الشراكة، والرسالة التعريفية، وبيانات التواصل، وروابط التذييل والتواصل الاجتماعي، وإعدادات النشرة وطرق الدفع المعروضة.

- بيانات التواصل مؤقتة عمدًا. لتفعيل قيمة حقيقية، حدّث `value` و`url` وغيّر `placeholder` إلى `false`.
- روابط الحسابات الاجتماعية `null` وغير مفعلة. وضع رابط حقيقي مكان `null` يفعّله في التذييل.
- تعديل `demoShipping` لوجهة يحدّث السعر المعروض والحساب في الخادم معًا.
- النشرة وطلبات الشراكة تُحفظ في قاعدة البيانات، لكن إرسال البريد/واتساب يحتاج ربط خدمة إرسال حقيقية؛ لا يكفي تغيير علامة الإعداد.
- عرض وسيلة دفع لا يعني اتصالها ببوابة دفع. جميع الوسائل الحالية محاكاة دون خصم أو بيانات بطاقات.
